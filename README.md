# .github

The GitHub organisation profile for sealb.in: `profile/README.md` is what
[github.com/Sealbin](https://github.com/Sealbin) shows.

`assets/org-banner.png` and `assets/org-avatar.png` are rendered in
[`Sealbin/website`](https://github.com/Sealbin/website) by
`tools/render-og.sh` (the banner is its `assets/readme-banner.png`). Re-copy
them here after a re-render. The avatar is uploaded by hand at
`github.com/organizations/Sealbin/settings/profile`; GitHub has no API for it.
